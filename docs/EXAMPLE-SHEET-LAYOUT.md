# Example Character Sheet Layout

This is the conceptual preview the skill should show or generate before intake.

```text
┌─────────────────────────────────────────────────────────┐
│                 CHARACTER ID / VERSION                  │
├──────────────┬──────────────┬──────────────┬────────────┤
│ FRONT FACE   │ 3/4 LEFT     │ 3/4 RIGHT    │ PROFILE    │
├──────────────┴──────────────┴──────────────┴────────────┤
│                 CLOSE-UP IDENTITY ROW                   │
│      EYES       MOUTH/LIPS       SMILE       HAIRLINE   │
├───────────────────────┬─────────────────────────────────┤
│ FULL BODY FRONT       │ FULL BODY SIDE / BACK           │
├───────────────────────┼─────────────────────────────────┤
│ HANDS / NAILS         │ BODY PROPORTION NOTES           │
├───────────────────────┴─────────────────────────────────┤
│ COLOR PALETTE                                            │
├─────────────────────────────────────────────────────────┤
│ LOCKED IDENTITY | EDITABLE APPEARANCE | EVIDENCE STATE  │
└─────────────────────────────────────────────────────────┘
```

The actual layout adapts to the selected level and available evidence.

## Base

Show only the strongest supported panels plus clearly marked reconstructed views when useful.

## Advanced

Add broader face-angle, body and expression coverage.

## Full

Add comprehensive identity, expression, body and detail panels when the reference set genuinely supports them.

## Visual rules

- neutral studio-style presentation;
- consistent camera logic where possible;
- minimal, neutral, non-sexualized base clothing;
- no seductive posing;
- no beautification that erases identity-specific asymmetry;
- do not visually imply that reconstructed panels are directly observed evidence.
