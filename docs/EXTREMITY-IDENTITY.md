# Hand and Foot Identity

Hands and feet are not cosmetic afterthoughts in pose-ready production.

Use `schemas/extremity-profile.schema.json`.

Track left/right separately when evidence exists.

## Hands

Useful identity/anatomy information includes:

- palm proportion;
- finger length pattern;
- knuckle prominence;
- hand width/length relationship;
- nail bed and nail shape;
- left/right asymmetry.

## Feet

Useful information includes:

- foot length/width relationship;
- toe length pattern when visible;
- arch/shape cues when visible;
- left/right asymmetry.

Do not invent detailed hand/foot identity when references do not show them.

For P3-P5, anatomy plausibility is critical even when extremity identity evidence is weak.

A plausible generic hand is not equivalent to an Observed hand identity.
